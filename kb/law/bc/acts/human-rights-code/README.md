# Human Rights Code

Only the sections strata questions reach: discrimination and the duty to accommodate (disability, family status, age).

**What goes here:** one Markdown item per section, type `act-section`, id prefix `bc.hrc.`. See `research/plan.md` (R3).

**source.json** describes the whole enactment: title, citation, chapter, url, consolidation date, licence, retrieved_at and `parts[]` (which Parts are in scope). The values currently in it are unverified placeholders (`retrieved_at` and `consolidation_date` are null). Confirm them against BC Laws when the first items are added; the validator requires both dates once the folder contains an item.

Empty until research fills it. Do not write statute text from memory.
