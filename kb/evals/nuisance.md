# Evals for nuisance

Each case lists the question, the scope it runs in, the points a correct answer makes, the kb ids it must cite, and what it must not say. A case whose expected result is "no grounding found" is testing that the assistant declines rather than guesses.

## Case 1: Which limb applies

- **Question:** A neighbour's cooking smells are coming into a unit. Which bylaw is that?
- **Scope:** a building with only the standard bylaws.
- **Expected points:** The standard use bylaw, on the nuisance or hazard limb or the unreasonable interference limb; naming the limb matters because the evidence differs. There is no odour bylaw unless the building has filed one.
- **Must cite:** `bc.spa.sched.bylaw3`
- **Must not say:** An odour-specific bylaw the building does not have; a conclusion that the smell is or is not a nuisance.

## Case 2: A rule for conduct inside a lot

- **Question:** Can we make a rule about smells from cooking inside units?
- **Scope:** any building.
- **Expected points:** No. Rules govern only the use, safety and condition of common property and common assets; conduct inside a strata lot needs a bylaw.
- **Must cite:** `bc.spa.s125`
- **Must not say:** That a rule can reach inside a strata lot.

## Case 3: Damage to common property

- **Question:** An owner's contractor scratched the lobby floor. Is that a bylaw matter?
- **Scope:** a building with only the standard bylaws.
- **Expected points:** The standard use bylaw prohibits causing damage other than reasonable wear and tear to common property, common assets and the parts of a strata lot the corporation must repair or insure, so it can be. Recovering the cost is a separate question from fining.
- **Must cite:** `bc.spa.sched.bylaw3`
- **Must not say:** That the owner can simply be invoiced without any process.

## Case 4: Enforcement

- **Question:** Can we fine for a nuisance straight away?
- **Scope:** any building.
- **Expected points:** Not without the complaint and answer process: a complaint, written particulars, a reasonable opportunity to answer including a hearing if requested, and written notice of the decision.
- **Must cite:** `bc.spa.s135`
- **Must not say:** That a nuisance is self-evident and needs no process.

## Case 5: No grounding: whether this is a nuisance

- **Question:** Is my neighbour's wind chime a nuisance?
- **Scope:** any building.
- **Expected points:** The "no grounding found" state as to the outcome. The answer can set out the limbs of the use bylaw, and must say the kb holds no decisions and cannot say how the test has been applied.
- **Must cite:** `bc.spa.sched.bylaw3`
- **Must not say:** A finding either way; a comparison to a decided case, since the kb holds none.
