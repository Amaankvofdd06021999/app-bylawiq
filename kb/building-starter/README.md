# Building starter kit

What a building needs to get useful answers on day one. Layer `building`.

- `standard-bylaws/` (type `standard-bylaw`): building-facing notes on the standard bylaws, each citing the law-layer `schedule` item it comes from. The standard bylaw text itself is in the law layer (`law/bc/acts/strata-property-act/schedule-of-standard-bylaws/`) and is not duplicated here. Standard bylaws apply to a building unless its registered bylaws replace them.
- `bylaw-patterns/` (type `bylaw-pattern`): common bylaw amendments (rental restrictions, pet limits, short-term rental bans) with the decisions that tested them.
- `document-checklist.md` (type `checklist`): documents to upload at onboarding and why.

These are starter content shared across buildings. A building's own documents never live in kb/; they are uploaded to the app and isolated per building by RLS.
