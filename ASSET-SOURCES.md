# BylawIQ application asset sources

The earlier BylawIQ website concept informed the application's type hierarchy, orange brand accents and neutral palette. The reference design was inspected at https://www.agiloft.com/ on 2026-09-13. Application copy adapts the supplied BylawIQ brief.

## Typography

Public availability does not grant a commercial font license. Font licensing remains with the typeface owners; supply appropriately licensed files for commercial launch.
